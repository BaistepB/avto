# СПЕЦИФИКАЦИЯ ПРИЛОЖЕНИЯ «АВТООТЧЕТ» (SPEC.md)

## 1. Общее описание и интеграция
- **Назначение:** веб-приложение для автоматизированного заполнения ежемесячного «Отчета об использовании топлива» и путевых листов с выгрузкой в `.xlsx` по корпоративному шаблону (`template.xlsx`).
- **Платформа:** адаптивное SPA в одном файле `index.html` (ПК, планшет, смартфон).
- **Будущее объединение:** независимый модуль будущего единого портала «Эксперт» (`sklad/`, `routes/`, `report/`). В шапке предусмотреть компактную структуру (место под будущую кнопку «← Меню», заголовок, переключатель режимов и кнопку настроек ⚙️).

## 2. Авторизация и хранение данных (Google Таблицы + localStorage)
- Эксперт авторизуется в приложении (данные заполняются 1 раз).
- Постоянное облачное хранилище — **Google Таблица** (через настраиваемый URL Google Apps Script Web App), локальный быстрый кэш — `localStorage` с префиксом `expert_report_*`.
- В Google Таблице хранятся:
  1. Профиль эксперта («Карточка сотрудника» + Точка старта).
  2. Личный справочник адресов эксперта.
  3. Кэш расстояний между парами адресов (экономия запросов API Яндекс Карт).
  4. История закрытых месяцев (год, месяц, конечный пробег, конечный остаток топлива).

## 3. Карточка сотрудника (заполняется 1 раз)
Поля профиля соответствуют вкладке **«Карточка сотрудника»** в шаблоне `template.xlsx`:
1. ФИО водителя
2. Должность (инженер/эксперт)
3. Организация
4. Норма расхода — лето (л/100 км)
5. Норма расхода — зима (л/100 км)
6. Марка автомобиля
7. Государственный номерной знак
8. Удостоверение № (Водительское)
9. Горючее (АИ-95, АИ-92, ДТ)
10. **Точка старта** — базовый адрес, с которого всегда начинается и которым всегда заканчивается маршрут каждого рабочего дня.

**Импорт профиля:** кнопка «Загрузить из отчета (.xlsx)» считывает поля 1–9 напрямую из вкладки «Карточка сотрудника» готового файла.

## 4. Настройка месяца и правила календаря
- Выбор **месяца и года** отчета.
- **Автопереключение сезонной нормы:**
  - с **1 апреля по 31 октября** — автоматически выбирается **летняя** норма;
  - с **1 ноября по 31 марта** — автоматически выбирается **зимняя** норма;
  - предусмотрен ручной переключатель на случай исключений.
- **Входящие данные на начало месяца (одометр и остаток топлива):**
  - Вариант 1: автоподстановка конечных значений прошлого месяца из Google Таблицы / локальной истории `expert_report_*`;
  - Вариант 2: импорт из загруженного `.xlsx` отчета за прошлый месяц;
  - Вариант 3: ручной ввод и редактирование.
- **Правило первого рабочего дня:** 1-е число месяца не обязательно является рабочим днём. Входящие одометр и остаток топлива фиксируются на начало месяца и автоматически переходят на **первый фактический рабочий день** (пустые нерабочие дни путевыми листами не заполняются).
- **Правило календаря:** выходных и праздничных дней нет — любой календарный день может быть рабочим. День, в который указана заправка, **всегда** автоматически становится рабочим.
- **Заправки:** таблица ручного ввода (Дата, Литры).
- **Импорт поездок из приложения «Маршруты»:**
  - Загрузка экспортированного файла (`routes_YYYY-MM.json` или `.csv`) с автоматической раскладкой поездок по датам.
  - Дополнительно: если в браузере (на том же домене) уже есть ключ `expert_app_route_history_v1`, предусмотреть кнопку «Подтянуть из истории браузера» (строго в режиме чтения).

## 5. Два режима работы
- **Переключение режимов:** на этапе разработки в шапке отображается видимый переключатель **«Официальный» / «Автоподбор»**.
- В коде заложить флаг `const HIDE_UNOFFICIAL_MODE = false;`. При переключении на `true` видимый переключатель скрывается, а «Автоподбор» открывается секретным действием (5 быстрых кликов по заголовку).

### Режим 1: Официальный
- Таблица/календарь месяца с подтянутыми поездками из «Маршрутов» и днями заправок.
- Эксперт вручную включает/выключает рабочие дни, вводит или правит пробег и промежуточные адреса.
- Первая и последняя точка маршрута каждого рабочего дня автоматически фиксируются как **Точка старта**.
- Показания одометра (начало/конец дня) и остаток топлива пересчитываются автоматически.

### Режим 2: Неофициальный (Автоподбор)
- **Входные параметры:** обязательные поездки из «Маршрутов», заправки по датам и **целевой остаток топлива на последний день месяца**.
- **Математика автоподбора:**
  1. `Требуемый расход (л) = Начальный остаток + Сумма заправок − Целевой остаток`.
  2. `Требуемый общий пробег (км) = (Требуемый расход / Активная норма) * 100`.
  3. `Недостающий пробег = Требуемый общий пробег − Суммарный пробег из «Маршрутов»`.
  4. Недостающий пробег распределяется по рабочим дням: дни заправок обязаны иметь пробег, остальные дни выбираются вручную или расставляются автозаполнением.
- **Построение реальных маршрутов (Яндекс Карты):**
  - География: **Россия, основной фокус — Москва и Московская область**.
  - Интеграция с **API Яндекс Карт** (ключ в настройках/конфиге) для расчёта реального дорожного пробега.
  - Петля каждого дня: `Точка старта → [промежуточные точки] → Точка старта`.
  - Источники промежуточных точек (на выбор или комбинированно):
    - **А)** Реальные адреса в радиусе от «Точки старта» (подбор через Яндекс Карты).
    - **Б)** Личный справочник адресов эксперта из Google Таблицы.
  - Кэширование расстояний между парами адресов в Google Таблице.

## 6. Экспорт итогового отчета (`.xlsx`)
- Кнопка **«Скачать отчет (.xlsx)»** формирует файл на базе `template.xlsx` через `ExcelJS` с сохранением верстки, стилей и формул:
  - **«Карточка сотрудника»** — заполняется из профиля.
  - **«Расчет»** — сводная таблица за месяц.
  - **«1» … «31»** — путевые листы на рабочие дни (одометр, заправки, маршрут от Точки старта до Точки старта).
- Итоговые конечный одометр и остаток топлива сохраняются в Google Таблицу (и в `expert_report_*`) для переноса в следующий месяц.
