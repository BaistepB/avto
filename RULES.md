# ПРАВИЛА РАЗРАБОТКИ ПРОЕКТА «АВТООТЧЕТ» (WORKSPACE RULES)

## 1. ПРЕЗУМПЦИЯ НЕПРИКОСНОВЕННОСТИ КОДА (КРИТИЧНО)
- Файл `index.html` является эталонной рабочей версией.
- КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО удалять, сокращать или переписывать существующий функционал, верстку, систему 9 тем, формулы расчёта пробега/топлива, парсер импорта или генератор `.xlsx`, если об этом нет ПРЯМОГО указания в текущем промпте.
- ЗАПРЕЩЕНО использовать заглушки вида `// ... остальной код ...` или сокращать функции.
- Не делай «рефакторинг ради рефакторинга» и не меняй структуру состояний (`useState`) без прямого запроса.

## 2. ПРОЦЕСС РАБОТЫ В ANTIGRAVITY
- Шаг 1: Прочитай запрос и сверься с `SPEC.md`.
- Шаг 2: Для любой задачи сложнее мелкой правки сначала создай Artifact с планом (`Implementation Plan`), укажи затрагиваемые блоки и подтверди, что остальной функционал не пострадает. Дождись одобрения.
- Шаг 3: Вноси точечные изменения (diff), не перезаписывая весь файл без необходимости.
- НЕ запускай браузерный агент без отдельного запроса.

## 3. ТЕХНИЧЕСКИЕ ОГРАНИЧЕНИЯ И ИЗОЛЯЦИЯ ПАМЯТИ
- **Однофайловая архитектура:** приложение работает в одном файле `index.html` (React 18 через Babel standalone + Tailwind CSS через CDN + ExcelJS через CDN). Не переписывай на Vite/Next.js и не дроби на модули.
- **Запрет `import.meta`:** внутри `<script type="text/babel">` не использовать `import.meta.env`. Все URL и ключи выносить в константы в начале скрипта с возможностью переопределения через `window.*` и окно настроек.
- **Изоляция `localStorage` (КРИТИЧНО для общего домена с «Складом» и «Маршрутами»):**
  - Все собственные данные этого приложения обязаны храниться ТОЛЬКО под ключами с префиксом `expert_report_*` (например, `expert_report_profile`, `expert_report_months`, `expert_report_settings`).
  - Общий ключ темы: `expert_app_theme` (при первом запуске, если пуст, проверить `expert_route_theme` или `sklad_theme`, иначе `'expert'`).
  - Ключ истории из «Маршрутов» (`expert_app_route_history_v1`) разрешено использовать **ТОЛЬКО на чтение**. Категорически запрещено перезаписывать или удалять его.
  - **ЗАПРЕЩЕНО вызывать `localStorage.clear()`!** Любая функция сброса в «Автоотчете» обязана удалять в цикле только ключи, начинающиеся с `expert_report_`.
- **Мобильная и планшетная адаптация:**
  - Все `<input>`, `<select>`, `<textarea>` обязаны иметь класс `text-[16px] sm:text-sm`.
  - В `<meta name="viewport">` обязательно сохранять `maximum-scale=1.0, user-scalable=no`.
  - Минимальная высота интерактивных кнопок — `48px` (`min-h-[48px]`).
- **Иконки:** только чистые инлайн SVG-иконки (без нестабильных внешних обёрток `<Icon/>`, дающих пустые отступы).
- **Работа с Excel (`.xlsx`):** использовать `ExcelJS` (через CDN) для сохранения стилей, формул и верстки шаблона.
